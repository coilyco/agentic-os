# Voice adaptation

Use this skill to preserve a person's recognizable reasoning and language while
adapting material for a new format, audience, or channel. Treat voice as an
evidence-backed transformation, not a list of stylistic adjectives.

## Establish the source of truth

Gather the authoritative voice guide, target register, source facts, privacy
constraints, and any phrases the author wants preserved. For consequential
ghostwriting, inspect a recent approved example in the target register when one
is available.

If no voice guide or representative sample exists, preserve the source's
language and reasoning closely. Ask for clarification only when the missing
context would materially change the result.

## Adapt the draft

1. Lead with the author's actual point instead of a generic hook.
2. Preserve epistemic state. Keep observations, hypotheses, conclusions,
   uncertainty, costs, and value distinct when the source distinguishes them.
3. Preserve useful texture such as characteristic transitions, sentence
   fragments, contractions, concrete details, and deliberate rough edges.
4. Adapt context, structure, and length to the target register without
   inventing a new persona.
5. Do not manufacture novelty, certainty, experience, emotion, or evidence.
6. Name any material transformation when presenting the result, especially a
   stronger claim, omitted caveat, reconstructed chronology, or supplied fact.
7. Apply the person's mechanical writing rules as a final lint pass.

Prefer a clear claim with adequate evidence over smooth but generic prose. A
recognizable draft may be slightly uneven. Do not polish away the reasoning
path that makes the voice identifiable.

## Return the result

Return the candidate text first. When it helps review, follow it with preserved
phrases, material transformations, and claims that still need verification.
Mark drafts as drafts. This skill grants no permission to publish, reply, or
change an account.

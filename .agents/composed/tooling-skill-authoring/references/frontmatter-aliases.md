# Frontmatter aliases

Lead with the canonical name plus 2-3 natural-language phrasings the human might reach for. **The hard ceiling on the whole `description:` field is validator-enforced, not a fixed prose number:** `validate_skills.py` reads `max_description_bytes` from that repo's `categories.yaml`. The public agentic-os default is **500 bytes**. Some repos tighten it - agentic-os-kai is at **200 bytes**, the kai-parity target the rest of the ecosystem is cascading toward. **Size a description to your repo's `categories.yaml` value, not a hardcoded number from memory** - the same skill symlinked into a tighter repo is held to that repo's cap. If a skill needs more trigger surface than the cap allows, the fix is a better name, a router parent (see `ward-meta`, `ops-social-gws-gmail`, `tooling-execution-mode` for the pattern), or splitting the skill. Not a longer description.

**Router-parent carve-out:** a router skill claiming a broad domain keyword surface (so child skills can stay terse) may exceed the cap when the extra surface is doing real routing work, not alias-packing, declared via a per-name `max_description_bytes` override in `categories.yaml`. The router shape has to be load-bearing - "router with two children" does not qualify. The Gmail and Google Calendar parents both do, today.

**Why:** the `description` field is eager-loaded into every Claude turn forever. Aliases are paid only per invocation. At ~100 skills, the eager surface already crowds the catalog, and the system-reminder skill catalog truncates past ~80 entries, so selection accuracy degrades from sheer surface size before token cost even enters the picture. Alias-packing is the most expensive possible layer to solve discoverability at. The cap dropped from 600 to 500 after the alias sweep (only 3 outliers remained over 500, all trimmable).

**How to apply:** when authoring a new skill, write `description:` as one sentence of purpose plus 2-3 phrasings. When tempted to add a fourth alias, rename the skill or hoist a router parent instead. A future cold-skill pruning audit chain will validate whether existing aliases earn their bytes.
